# Замер скорости скачивания

Скрипт на Node.js делает 10 последовательных запросов к указанному адресу,
дожидаясь полного ответа на каждый, и выводит среднее время запроса,
общий объём данных и скорость скачивания.

## Требования

Node.js 18 или новее (используется встроенный `fetch`). Зависимости не нужны.

## Запуск

```bash
node index.js <url>
```

Пример:

```bash
node index.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

## Что выводится

- время и размер каждого запроса;
- среднее время запроса, мс;
- общий объём скачанных данных, МБ;
- скорость скачивания.

## Единицы измерения

- время: миллисекунды (мс);
- объём: мегабайты (1 МБ = 1024 × 1024 байт);
- скорость: **МБ/с** (мегабайты в секунду) и дополнительно **Мбит/с**
  (МБ/с × 8), как её обычно указывают провайдеры.

Скорость считается как общий объём данных, делённый на общее время всех запросов.

## Обработка ошибок

Если адрес не передан, сервер ответил не 2xx или запрос упал (нет сети, неверный URL),
скрипт выводит сообщение об ошибке и завершается с кодом 1.
